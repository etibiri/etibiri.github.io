Installation de l'Environnement de Travail

Guide pour installer les outils nécessaires à la bioinformatique.

Installation de WSL (Windows Subsystem for Linux)

Pour plus d'informations, consultez le guide officiel de WSL pour Windows.

Étapes d'installation :

  1. Sur ton ordi Windows, Clique sur le bouton Démarrer
  2. Tape PowerShell
  3. Clique droit sur Windows PowerShell → sélectionne "Exécuter en tant qu’administrateur"
  4. Activation de WSL
    wsl --install
  5. Voir la liste des distributions Linux disponibles :
    wsl -l -o
  6. Installer une distribution spécifique (ex. Ubuntu 24.04 LTS) :
    wsl --install -d Ubuntu-24.04

Mise à jour et installation des outils essentiels

Ouvrez votre terminal WSL et exécutez :

sudo apt update && sudo apt upgrade -y

Ensuite, installez les autres outils python et les packages bioinformatique : FastQC, Minimap2, Samtools :

sudo apt install -y python3 python3-pip git

Installation de FastQC :

sudo apt update
sudo apt install fastqc

Installation de Minimap2 :

sudo apt update
sudo apt install minimap2

Installation de Samtools :

sudo apt update
sudo apt install samtools

Vérification de l'installation

Exécutez les commandes suivantes pour installer python et jupyter :

python3 --version
git --version
jupyter --version
fastqc --version
minimap2 --version
samtools --version

Si les versions s'affichent, votre environnement est prêt ! 🎉
