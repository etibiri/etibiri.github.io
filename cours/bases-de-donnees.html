Bases de données biologiques et ressources en ligne

Partie 4.2 du cours. Support de cours : diapositives (PDF).

Objectifs

  • Comprendre l’organisation des ressources de données du NCBI et de l’EBI.
  • Faire la différence entre une base de données, un outil et un dépôt (repository).
  • Rechercher des données dans une base à l’aide d’un numéro d’accès, d’un nom de gène, etc.
  • Utiliser les ressources du NCBI et de l’EBI.

1. Pourquoi s’y intéresser ?

Il existe un très grand nombre de bases de données et de ressources en ligne. Avant de chercher une donnée, il faut savoir :

  • quelles bases de données et ressources existent ;
  • quels outils permettent de les exploiter ;
  • quels outils permettent d’y faire des recherches.

2. Qu’est-ce qu’une base de données biologique ?

Une base de données biologique peut être :

  • publique ou privée ;
  • consacrée aux protéines, nucléotides, structures, à la littérature, aux annotations… ;
  • généraliste ou spécialisée ;
  • centrée sur la séquence (acides aminés ou nucléotides) ou sur le génome.

3. Bases primaires et bases secondaires

Bases de données primaires

Elles stockent les séquences telles qu’elles ont été déposées par les chercheurs. Les trois grandes bases de séquences nucléotidiques forment l’INSDC (International Nucleotide Sequence Database Collaboration) :

  • GenBank, au NCBI (États-Unis) ;
  • ENA (European Nucleotide Archive), à l’EMBL-EBI (Europe) ;
  • DDBJ (DNA Data Bank of Japan), au Japon.

Les trois bases échangent leurs données quotidiennement : une séquence déposée dans l’une se retrouve dans les deux autres. Chacune a ses propres outils de recherche, mais un même numéro d’accès est valable dans les trois.

Bases de données secondaires

Elles sont construites à partir des données primaires et y ajoutent des informations : annotation, curation, classification. Exemples : RefSeq (séquences de référence non redondantes du NCBI), UniProtKB/Swiss-Prot (protéines annotées manuellement), Pfam (familles et domaines protéiques).

À retenir : la base primaire conserve la donnée brute déposée ; la base secondaire apporte une interprétation de cette donnée.

4. Les deux grandes ressources : NCBI et EMBL-EBI

NCBI (National Center for Biotechnology Information)

Le portail ncbi.nlm.nih.gov donne accès à plus de 30 bases de données depuis un même champ de recherche, avec un menu déroulant pour choisir la base. Elles se regroupent ainsi :

DomaineBases du NCBI

Gènes et expressionGene, GEO (Gene Expression Omnibus), PopSet

ChimiePubChem

EMBL-EBI (European Bioinformatics Institute)

L’EMBL-EBI, sur ebi.ac.uk, entretient l’une des gammes les plus complètes de bases de données moléculaires libres d’accès (ENA, UniProt, Ensembl, InterPro, PDBe…). Il propose aussi des formations en ligne gratuites pour apprendre à utiliser ses ressources : ebi.ac.uk/training.

5. Les bases de données spécialisées

Il existe un grand nombre de bases consacrées à un organisme, un pathogène ou un type de données. En général :

  • la plupart de leurs séquences se trouvent aussi dans GenBank/ENA ;
  • elles peuvent contenir des génomes entiers ;
  • elles offrent des ressources et des outils propres à leur thématique.

Exemples :

  • PlasmoDB : génomes de Plasmodium ;
  • Wellcome Sanger Institute : collections spécialisées ;
  • HCV Database (Los Alamos) : virus de l’hépatite C ;
  • BV-BRC : bactéries et virus, qui intègre l’ancienne base grippe Influenza Research Database.

6. Dessiner des amorces avec Primer-BLAST

Primer-BLAST (NCBI) dessine des amorces PCR à partir d’une séquence ou d’un numéro d’accès, puis vérifie par BLAST qu’elles n’amplifient que la cible voulue.

7. Exercices

  1. Sur le NCBI, recherchez le gène 16S ribosomal RNA d’Escherichia coli dans la base Nucleotide. Notez le numéro d’accès, la longueur et l’organisme d’une séquence.
  2. Retrouvez la même séquence sur l’ENA à partir de son numéro d’accès. Qu’est-ce qui change dans la présentation ?
  3. Téléchargez cette séquence au format FASTA. Vous la réutiliserez dans la partie Linux.
  4. Sur UniProt, trouvez une protéine de votre choix annotée dans Swiss-Prot. Quelles informations ajoute-t-elle par rapport à la séquence brute ?

À retenir

  • Une grande quantité de données biologiques est disponible librement.
  • Les bases primaires stockent les séquences brutes ; les bases secondaires apportent l’annotation.
  • Il est important de savoir comment et où les données sont stockées.
  • Le NCBI et l’EBI sont les deux ressources les plus utilisées pour obtenir des données biologiques.
